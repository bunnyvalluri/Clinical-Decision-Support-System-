# Bug Bounty Draft Reporting Policy

## 1. Supported Formats
The system supports generating draft reports for:
- HackerOne
- Bugcrowd
- Intigriti
- Immunefi
- YesWeHack

## 2. Invariant: Draft Only
Agents are strictly prohibited from submitting external HTTP requests to bug bounty platform APIs. Reports are generated in `DRAFT` status and can only be exported or processed after explicit human review and cryptographic dual-custody authorization.

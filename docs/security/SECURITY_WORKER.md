# Security Worker & Process Isolation

## Dedicated Worker Architecture
Security scans run in a sandboxed, isolated environment separated from standard web application workers:

- **Celery Queue**: `security_scans`
- **Execution Limits**:
  - `time_limit`: 300 seconds
  - `soft_time_limit`: 270 seconds
  - Concurrency: Restricted to prevent target exhaustion
  - Rate limiting: 5 requests/second default
- **Credential Quarantine**:
  - Security workers receive NO production database credentials, Django secret keys, or cloud master credentials.
  - Test authentication utilizes strictly synthetic tokens generated by `SyntheticSecurityDataGenerator`.
- **Emergency Abort**:
  - The security orchestrator provides an immediate abort method `trigger_emergency_stop()` that cancels active scan operations and marks status as `CANCELLED`.

# Loop Engineering Documentation

## 1. Overview
Loop Engineering integrates the pattern library and operational tooling from `@cobusgreyling/loop` into the Healthcare CDSS platform. It serves as a **controlled engineering automation and governance layer**, coordinating coding agents (Cline, Ruflo) around safe worktrees without exposing clinical decision models or production databases.

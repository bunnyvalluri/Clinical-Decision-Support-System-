# Local RAG & Vector Embeddings with Ollama

## 1. Local RAG Pipeline Architecture

```
+-----------------------------------------------------------------------------------------------+
|                                      CLINICAL KNOWLEDGE BASE                                  |
| (Clinical Practice Guidelines, Hospital Protocols, Sepsis Guidelines, Antibiotic Formularies)  |
+-----------------------------------------------------------------------------------------------+
                                                |
                                                v
+-----------------------------------------------------------------------------------------------+
|                       DOCUMENT CHUNKING (512 - 1024 tokens with overlap)                     |
+-----------------------------------------------------------------------------------------------+
                                                |
                                                v
+-----------------------------------------------------------------------------------------------+
|                        OLLAMA EMBEDDINGS SERVICE (`nomic-embed-text`)                        |
|                                (Vector dimension: 768)                                        |
+-----------------------------------------------------------------------------------------------+
                                                |
                                                v
+-----------------------------------------------------------------------------------------------+
|                     HYBRID VECTOR STORAGE (Neon pgvector + Meilisearch)                       |
+-----------------------------------------------------------------------------------------------+
                                                |
                                                | Query: Patient condition + guidelines
                                                v
+-----------------------------------------------------------------------------------------------+
|                           RELEVANCE RANKING & RECIPROCAL RANK FUSION                          |
+-----------------------------------------------------------------------------------------------+
                                                | Top-K Approved Chunks
                                                v
+-----------------------------------------------------------------------------------------------+
|                         OLLAMA REASONING SYNTHESIS (`llama3.3:8b`)                            |
|             (Generates evidence-backed synthesis referencing guideline section IDs)           |
+-----------------------------------------------------------------------------------------------+
```

## 2. Embedding Model Specification
- **Default Model**: `nomic-embed-text:latest`
- **Vector Dimension**: `768`
- **Alternative High-Capacity**: `bge-m3:latest` (1024 dimensions)
- **Distance Metric**: Cosine Similarity / Inner Product
- **Registry Record**: Model metadata and dimensions are verified in `EmbeddingRegistry` before writing vectors to prevent dimension mismatch corruption.

## 3. Grounding & Anti-Hallucination Guardrails
1. The LLM prompt enforces: *"If the provided clinical guidelines do not contain the answer, state that there is insufficient local evidence. Do not extrapolate outside approved guideline texts."*
2. Each assertion generated by the model must cite its retrieved chunk identifier.
